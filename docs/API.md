# API

Interactive documentation (Swagger) is generated by FastAPI at **http://localhost:8000/docs**
(also proxied by the frontend dev server). Base path: `/api`.

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Liveness + system metrics (CPU, memory, tick time, DB state) |
| GET | `/api/system/events?limit=` | Operational event log |
| GET | `/api/cameras` | Cameras with status; stream credentials masked (`user:***@`) |
| POST | `/api/cameras` | Create/update a camera (validated; one enabled camera per approach) |
| DELETE | `/api/cameras/{id}` | Remove a camera |
| POST | `/api/cameras/{id}/reconnect` | Restart that camera's receiver |
| GET / PUT | `/api/cameras/{id}/regions` | Approach polygon, queue polygon, stop line, queue length (normalised 0–1) |
| GET | `/api/cameras/{id}/stream.mjpeg?overlay=1&fps=8&max_width=640` | Live MJPEG for `<img>`; boxes/regions drawn server-side; encoded only while watched |
| GET | `/api/cameras/{id}/snapshot.jpg?overlay=0` | Single frame (region editor) — 404 when offline |
| GET | `/api/traffic/current` | Full live snapshot (same payload as the WebSocket) |
| GET | `/api/traffic/recent?seconds=` | 1 Hz points from memory (≤ 30 min) for live charts |
| GET | `/api/traffic/history?minutes=&bucket_s=` | Bucketed per-approach averages from the database |
| GET | `/api/traffic/history.csv?minutes=&bucket_s=` | Same as history, as a CSV download |
| GET | `/api/congestion` | Current scores, components and model config |
| POST | `/api/congestion/config` | Set weights (must sum to 1) / norms (persisted) |
| GET | `/api/priority` | Current decision, ranking, reason, config |
| GET | `/api/priority/history?limit=` | Stored decisions |
| GET | `/api/simulation/state` | Signal stage, colours, timers, events |
| POST | `/api/simulation/config` | Min/max green, yellow, clearance, pre-emption min green, starvation, max-skip (persisted) |
| POST | `/api/simulation/demand` | Arrival rate of the demo model (used where no camera data) |
| POST | `/api/simulation/pedestrian` | Placeholder pedestrian call on an approach |
| GET / POST | `/api/vision/config` | enabled, model, conf, imgsz, device (persisted) |
| GET | `/api/vision/detections?camera_id=&limit=` | Finished vehicle tracks: class, confidence, departed, wait_s |
| GET / POST | `/api/system/config` | `data_source`: auto / vision / demo (persisted) |
| GET / POST | `/api/sites`, `/api/sites/active` | Study sites (proposal nodes); switch the active site |
| GET | `/api/evaluation` | Adaptive vs fixed-time comparison: delay, vehicle-hours, throughput, queues, stop rate, series |
| POST | `/api/evaluation/config`, `/api/evaluation/reset` | Fixed plan greens, saturation flow (persisted; starts a new run) |
| GET | `/api/evaluation/runs` | Latest saved result of each run at the active site |
| GET / POST | `/api/indices`, `/api/indices/config` | Congestion Index per approach; free-flow speed, default section, window |
| GET | `/api/incidents?status=active\|all` | Active incidents and log; POST `/api/incidents/{id}/acknowledge`; POST `/api/incidents/config` |
| POST / DELETE | `/api/simulation/preempt` | Simulated emergency pre-emption {approach, hold_s, reason} |
| GET / POST / DELETE | `/api/surveys/moving-car` (+ `.csv`) | Moving-car run pairs with computed flow, journey time, speed, CI and per-corridor summary |
| GET / POST / DELETE | `/api/surveys/validation` | Manual-count sessions compared with tracked vehicles; overall accuracy |
| GET | `/api/analytics/periods?days=&weekdays_only=` | Peak (07–09, 16–19) vs off-peak means per approach |
| GET | `/api/analytics/forecast?horizon=` | 15-minute arrival forecast per approach (Holt) with MAE |
| WS | `/ws/live` | `{"type":"snapshot", ...}` once per tick |
